

# STM32 ADC多通道DMA采集配置总结

## 问题回顾与解决

在配置过程中遇到的几个关键问题及解决方案：

### 🔍 配置问题分析

1. **多通道配置不完整** - 只配置单个DMA通道，无法支持多通道采集
2. **触发源冲突** - 同时配置外部触发和软件触发导致系统冲突
3. **ADC校准顺序错误** - 未遵循先使能后校准的正确流程
4. **DMA地址配置错误** - 缺少取地址符号导致地址指向错误
5. **硬件认知不足** - 未意识到STM32F103C8T6只有ADC1支持DMA功能

## 📋 完整的配置流程

### 第一阶段：基础配置

1. **时钟系统使能**
   - 开启TIM时钟（如使用定时器触发）
   - 开启GPIO时钟（对应ADC通道引脚）
   - 开启ADC时钟
   - 开启DMA时钟

### 第二阶段：外设初始化

2. **ADC初始化配置**
   
   - 设置ADC工作模式（独立模式）
   - 配置触发源选择（软件触发或硬件触发）
   - 开启扫描模式（多通道必需）
   - 设置连续转换模式
   - 配置数据对齐方式
   - 指定通道数量

3. **ADC通道配置**
   
   - 为每个通道设置转换顺序
   - 配置各通道采样时间
   - 确保通道数与实际使用一致

4. **DMA初始化配置**
   
   - 明确数据传输方向（外设到内存）
   - 设置外设基地址（ADC数据寄存器）
   - 设置内存基地址（数据缓冲区）
   - 配置数据传输量（字节、半字或字）
   - 设置地址递增模式
   - 选择DMA工作模式（循环或单次）

### 第三阶段：系统启动

5. **外设使能与校准**
   
   - 使能DMA功能
   - 使能ADC模块
   - 执行ADC校准流程
   - 配置ADC的DMA请求功能

6. **启动转换**
   
   - 调用软件触发函数启动转换
   - 在连续转换模式下只需单次触发

## ⚠️ 关键注意事项

### 硬件限制

- **STM32F103系列只有ADC1支持DMA功能**
- ADC2和ADC3无法实现DMA自动数据传输

### 配置一致性

- **避免触发源冲突** - 选择单一触发方式
- **模式匹配** - 多通道必须开启扫描模式
- **连续转换需要相应配置** - 确保工作模式一致

### 操作顺序

- **校准必须在使能之后** - 严格遵循操作时序
- **地址正确性** - DMA外设地址需要正确取址

### 数据传输

- **数据宽度匹配** - 确保外设与内存数据宽度一致
- **缓冲区管理** - 合理设置数据缓冲区大小

## 🔄 数据流向示意图

```
ADC输入引脚 
    ↓
ADC转换器 
    ↓
DR数据寄存器 
    ↓
DMA控制器 
    ↓
内存缓冲区
```

这种配置实现了完全自动化的数据采集和传输系统，CPU只需定期从内存缓冲区读取处理后的数据，大大提高了系统效率。
